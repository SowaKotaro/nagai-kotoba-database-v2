### 状態の書き方

- `未着手` → `済`（成果物と同じコミットで書き換える）。`作業中` はコミットしない。

- `見送り`: やらないと決めたもの。理由を備考に書く。
- `保留`: オーナーの判断待ち。何を判断してほしいかを備考に書く。

各単位の手順:
1. 監査記録を読む。
2. `git diff a04f375..HEAD --stat` で、指摘の対象ファイルのうち変わったものだけを開いて確かめる。
3. 指摘を「有効 / 陳腐化 / 重複 / 要確認」に分ける。
