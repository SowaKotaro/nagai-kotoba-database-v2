## §5.3 から: 一覧の行を 3 段から 2 段に畳んだときの実測（2026-09-06）

- 3 段（語 → 読み → 分類・種別・文字数）に積んでいたのを 2 段に畳んだ。
  実測: **1 行 109px → 65px、100 件のページ全長 12,244px → 7,765px（13.6 画面 → 7.8 画面）**、
  1 画面目に見える件数は 3〜4 件 → **7 件**（2026-09-06 オーナー指摘「縦に情報を積んでいるせいで一画面の情報量が落ち、最下部までのスクロール量が大きい」）。

## §5.7 から: About の線画 5 案（2026-09-09。すべて不採用）

「サイトの成り立ちを表す線画」として**5 案を実データで試作し、すべて不採用**になった経緯があるので、同じ道を辿らないよう残す。

| 案 | 中身 | 不採用の理由 |
|---|---|---|
| 渦（うず） | 収録語の読みを「・」で連ねて外へ向かう螺旋に載せる（`<textPath>`） | 図としては成立したが、About に図そのものが要らないという判断 |
| 同心円 | 1 本の円が 1 語。分割数＝読みの文字数、半径＝長さ | 説明なしでは何の図か伝わらない |
| 連なる円環 | サイト名の円環に収録語の円環が続く | ホームの印と絵柄が近く「同じものをもう一度」に見える |
| 三工程の説明図 | 拾う → 読みを与える → 軸で引く の 3 円 | ラベル（英字＋日本語）を持つぶん装飾ではなく図解になり、静けさから外れる |
| サイト名の読みの円環 | ホーム最上部の印と同じ図を 240px で | 一度は採用したが、**最終的に「このページに図は無し」**に落ち着いた |

## §5.8 から: 標識を白抜きにする試作の実測（2026-09-05。不採用）

標識を白抜き（アウトライン）にする案は試したうえで不採用（2026-09-05 オーナー判断）。`.figure-number` と質感を揃え、
ダークで白い線が浮くのをアクセントにする狙いだったが、**最終的に塗りへ戻した**。同じ道を辿らないよう、実測と経緯を残す。
- **級数ごとに適正な線幅が違い、幅が狭い**。12px での実測（線の画素そのものを測ったもの）:
  0.5px=2.53 ✗ / 0.7px=3.34 ✗ / **0.85px=4.72 ✓** / 1px=5.80 だが**塗り潰れて白抜きに見えない**（太字に見え §2 に反する）。
  成立するのは 0.85px 付近だけで、**10px には使えない**（溶けるか潰れる）。
- **大きくすると別の問題が次々に出る**: 16px 横組みは成立（5.80）。20px の 1 語 1 行の縦積みは袖では柱になるが、
  ページ見出しでは `PAGE 1 / 15` が「1 /」「15」に割れて**スラッシュが行末に残る**。
  30px ＋ `.figure-number` の書体では、級数を `clamp(44px, 5.5vw, 68px)` にできない
  （最長語 `RECENTLY`/`READINGS` が **332px** になり袖 152px を溢れて**本文に重なる**）。
