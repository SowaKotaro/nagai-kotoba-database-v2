# ジャンル階層（大分類・中分類の一覧）

日本十進分類法（NDC）を下敷きにした独自の3階層分類。**この文書は `app/models/seed_catalog.rb` の
`SeedCatalog::GENRES` を人が読める形に写したもので、正（単一の情報源）はコード側**。
ジャンル名を変える・足すときは `SeedCatalog` を直し、本書を合わせて更新する。

## 階層の決まり

- **大（level1）→ 中（level2）→ 小（level3）** の3階層。`genres.parent_id` の隣接リストで持つ。
- `word_senses.genre_id` は **必ず末端（小分類）** を指す。中・大は `parent_id` を辿って一意に導出する。
- **数値の分類コード列は持たない**（名前と親子関係だけ）。下の見出しの番号は NDC の類に対応する
  読み位置の目印で、DB には保存していない。
- **小分類（level3）は seed で管理しない**。アノテーション運用の中で管理画面（`/admin/annotations`
  のジャンルピッカー、`/admin/tags/genres`）から随時追加する。
- 同じ親の下で同名は作れない（`UNIQUE(parent_id, name)` ＋ モデルの `validates :name, uniqueness: { scope: :parent_id }`）。

## リネーム・統合するときの手順

`/admin/tags/genres` で seed 管理のジャンル（画面に「seed」印が付くもの）を改名・統合したら、
**`SeedCatalog` も必ず同時に更新する**。更新しないままデプロイすると `deploy:seed` が旧名を
再作成して重複する（2026-07-10 に本番で発生した事故。Issue 49）。

- **リネーム**: `GENRES` の名前を新名に書き換え、`GENRE_RENAMES` に `"旧パス" => "新名"` を追記する
  （キーは `"大分類名"` または `"大分類名/中分類名"`）。seed 実行時に他環境も自動で追従する。
- **統合（名前の廃止）**: `GENRES` から名前を削除する。残すと次のデプロイで復活する。
- 移行先の名前が既にある場合、seed は改名せず警告を出してスキップする（データが付いている
  可能性があるため機械的に統合しない）。統合は `/admin/tags/genres` の統合パネルで行う。
